Política de privacidad – Herramienta de sincronización interna de CompStrategy

Última actualización: 14 de octubre de 2026

CompStrategy utiliza una aplicación interna llamada "rclone" para sincronizar archivos de trabajo entre un repositorio privado de GitHub y la cuenta de Google Drive de CompStrategy. Esta aplicación es de uso exclusivo de CompStrategy y no está disponible para terceros.

Datos a los que accede

La aplicación accede únicamente a la cuenta de Google Drive de CompStrategy, con el único fin de crear, actualizar, mover y eliminar los archivos que se sincronizan. No accede a cuentas de otras personas.

Uso de los datos

Los datos se utilizan solo para realizar la sincronización. No se venden, no se comparten con terceros, no se usan con fines publicitarios y no se utilizan para entrenar modelos de inteligencia artificial.

Almacenamiento y seguridad

Las credenciales de acceso se guardan cifradas en GitHub y en el equipo del titular. Los archivos permanecen en Google Drive y en el repositorio privado de GitHub de CompStrategy.

Revocación del acceso

El acceso puede revocarse en cualquier momento desde https://myaccount.google.com/permissions.

Cumplimiento

El uso de la información recibida de las API de Google se ajusta a la Política de Datos del Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.
